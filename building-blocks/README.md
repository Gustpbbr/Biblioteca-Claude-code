# 🧱 Building blocks — peças prontas

Componentes reutilizáveis do Claude Code. A ideia é **copiar** o que você
precisa para o `.claude/` (ou raiz) de qualquer projeto.

Cada peça traz um cabeçalho explicando **o que faz** e **como instalar**.

## Conteúdo

| Pasta | O que tem |
|-------|-----------|
| [`commands/`](./commands/) | Slash commands reutilizáveis |
| [`agents/`](./agents/) | Subagents prontos |
| [`hooks/`](./hooks/) | Hooks (lint, test, format, guard-rails) |
| [`skills/`](./skills/) | Skills reutilizáveis |
| [`settings/`](./settings/) | Templates de `settings.json` |
| [`claude-md/`](./claude-md/) | Templates de `CLAUDE.md` por tipo de projeto |

> 🚧 As pastas estão prontas para receber peças. A preencher.
